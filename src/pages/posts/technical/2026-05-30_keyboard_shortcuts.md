When I was a student, I didn't know that learning shortcuts could be helpful, so I would use the mouse and click the "Back" or "Save" button every time I wrote an essay.  
Now that I'm used to using shortcuts, using the mouse each time I want to save or edit the document feels like a waste of energy.

I used Windows devices at work, so I got used to Windows shortcuts.   
I thought it could be satisfying to list all the shortcuts I've been using for years, so that I can see how much I've learned. I can use this as a cheat sheet, of course!

### General shortcuts
- `Ctrl` + `C` to copy
- `Ctrl` + `X` to cut
- `Ctrl` + `V` to paste
- `Ctrl` + `S` to save
- `Ctrl` + `Z` to undo
- `Ctrl` + `Y` to redo
- `Ctrl` + `A` to select all
- `Ctrl` + `F` to search
- `F2` to rename a file
- `Ctrl` + `B` to make selected text bold
- `Ctrl` + `U` to underline
- `Win` + `I` to open settings
- `Win` + `Shift` + `S` to take a screenshot

### File Explorer shortcuts
- `Win` + `E` to open File Explorer
- `Ctrl` + `Shift` + `N` to create a new directory
- `Ctrl` + `Space` to clear the current selection[^1]

### Excel shortcuts
- `Ctrl` + `;` to insert the current date
- `Ctrl` + `:` to insert the current time
- `Ctrl` + `Space` to select a column
- `Shift` + `Space` to select a row

### Browser shortcuts
- `Alt` + Right Arrow to go forward
- `Alt` + Left Arrow to go back
- `Ctrl` + `H` to open a browser's history
- `Ctrl` + `W` to close the current tab
- `Ctrl` + `T` to open a new tab

### VSCode shortcuts
- `Ctrl` + <code>`</code> to open the terminal
- `Ctrl` + `K`, then `Ctrl` + `F` to format selected code
- `Ctrl` + Backslash key to split the screen
- `Ctrl` + `Shift` + `P` to open the command palette

----------

[^1]: I've heard that this shortcut doesn't work in every environment.
