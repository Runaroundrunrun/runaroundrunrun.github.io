学生時代、ショートカットキーがどれだけ便利かわかっていなかったので、レポートをパソコン使って書くときなんかはマウスで「戻る」とか「保存」ボタンをいちいちクリックしていた。

ショートカットキーを使い慣れた今となっては、キーボードとマウスを交互に使う頻度を減らさないなんて、なんてエネルギーの無駄だったんだろう！と思うくらいになっている。

ここ数年、社会人になってから使うようになったショートカットキーを並べたら達成感あるんじゃないか？と思ったので、リストを作ってみた。  
（前職では Windows 端末を使っていたので、リストはすべて Windows のショートカットキーである）

もちろん自分用のチートシートにもなるし！

### 汎用的なショートカット
- `Ctrl` + `C`: 選択部分のコピー
- `Ctrl` + `X`: 選択部分の切り取り
- `Ctrl` + `V`: 貼り付け
- `Ctrl` + `S`: 保存
- `Ctrl` + `Z`: 戻る
- `Ctrl` + `Y`: 進む
- `Ctrl` + `A`: 全選択
- `Ctrl` + `F`: ページ内検索
- `F2`: ファイル名の変更
- `Ctrl` + `B`: 選択部分を太字にする
- `Ctrl` + `U`: 選択部分に下線をつける
- `Win` + `I`: 「設定」を開く
- `Win` + `Shift` + `S`: スクリーンショットをとる

### ファイルエクスプローラーを使うときのショートカット
- `Win` + `E`: ファイルエクスプローラーを開く
- `Ctrl` + `Shift` + `N`: 新しいディレクトリ（フォルダ）の作成
- `Ctrl` + `Space`: 選択状態の解除[^1]

### Excel ショートカット
- `Ctrl` + `;`: 現在日付の挿入
- `Ctrl` + `:`: 現在時刻の挿入
- `Ctrl` + `Space`: 列の選択
- `Shift` + `Space`: 行を選択

### ブラウザで使えるショートカット
- `Alt` + 右矢印: 進む
- `Alt` + 左矢印: 前のページに戻る
- `Ctrl` + `H`: 閲覧履歴を開く
- `Ctrl` + `W`: 現在のタブを閉じる
- `Ctrl` + `T`: 新しいタブを開く

### VSCode を使うときのショートカット
- `Ctrl` + <code>`</code>: ターミナルを開く
- `Ctrl` + `K`の後に`Ctrl` + `F`: コードの整形
- `Ctrl` + `\`: ビューの分割
- `Ctrl` + `Shift` + `P`: コマンドパレっとを開く

----------

[^1]: このショートカットが使えない環境もある模様。
